# Built-in summary engine: llama.cpp's server as a short-lived helper process

To work for people who won't install Ollama, heyListen writes summaries itself by default: `setup` downloads a pinned llama.cpp release (checked against its SHA-256), and for each summary heyListen starts `llama-server` on 127.0.0.1 with Borealis, sends the transcript, and stops it again. If Ollama already has Borealis, its file is used directly, since it's byte-identical to the Hugging Face Q4_K_M GGUF, so it isn't downloaded twice. We chose a helper process over linking llama.cpp into heyListen because whisper.cpp and llama.cpp each bundle their own ggml, and linking both into one binary conflicts. A helper also keeps the app small, and builds and updates on its own schedule. Ollama stays available as `summary_engine = "ollama"`, to use any model it has.
